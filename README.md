# LYDION-2D

**LYDION** (**LY**man-α **DI**ffus**ION**) **2D** is a Julia code that solves the time-dependent Lyman-α (Lyα) diffusion radiative transfer (RT) equation for an axi-symmetric cloud (i.e. in 2D space). The solver uses the Douglas-Rachford **A**lternating-**D**irection **I**mplicit (ADI) method to get the Lyα intensity J(R, Z, ν, t).
